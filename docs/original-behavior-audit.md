# 原版 WeatherKit 的用途、参数与 Fork 行为核对

历史记录说明：下文保存 2026-11-05 的行为核对。2026-11-14 已移除其中所述附加缓存、合并、冷却、统计、地区回退与备用查询；保留原有 12 项默认值，新增默认 Auto 的预警正文语言选项。当前处理与验证以 [后续修复](verified-followup-2026-11-14.md) 为准，旧描述不代表这些已移除功能仍可启用。

## 原版具体做什么

插件运行在代理客户端中，处理 Apple 天气接口的请求与响应。它先补齐可用数据类型，再按用户配置选取要处理的产品、来源和指数标准；信息来自 Apple 或所选的第三方供应商。

| 原版功能 | 实际处理 | 默认与约束 |
| --- | --- | --- |
| 解锁天气数据类型 | 合并 availability 能力列表，保留 Apple 新增能力 | 不凭空制造观测值；请求未选中的数据不进行来源替换 |
| 天气数据 | 用彩云或和风合并实况、小时和每日预报，按相同时间匹配 | 默认彩云，仅 CN；WeatherKit 选项保留 Apple 来源 |
| 分钟降水 | Apple 缺少该产品时才尝试补充 | 默认彩云；已有产品保留，无降水时面板可能隐藏 |
| 天气预警 | 按来源取得并合并预警、构造详情 | 默认和风网页；WeatherKit 选项保留原预警 |
| 污染物浓度 | 从所选来源补充物理浓度 | 默认彩云；浓度补充与指数替换是两项不同处理 |
| 空气指数 | 只针对选中的原始标准，使用指定来源或算法生成指数 | 默认替换 HJ6332012，来源 Calculate、算法 EU_EAQI |
| 昨日对比 | 已有对比按开关保留，缺失或明确要求重算时才取昨日来源 | 默认不因今日改动而覆盖已有对比；昨日来源独立选择 |

所有算法不一定使用全部六种污染物。单位转换、分项指数和总体指数各有含义，不能为了填满界面而虚构不适用的分项。None 表示不进行本地指数转换。

## 插件各段是什么意思

- `[Argument]`：正式版原有 12 项参数，选择数据集、天气／预警／分钟降水／污染物来源、内置算法、API 配置、储存优先级和日志。完整高级参数由 BoxJs 提供；本 Fork 另外提供缓存、诊断、地区回退及明确开启的备用查询参数。
- `[Rule]`：原版包含分析请求阻断及 Apple QUIC 限制，配合天气 HTTPS 处理；本轮不扩大这些规则。
- `[Script]`：availability 补充能力，airQualityScale 处理标尺路径及 HK/CN 自定义图例，weatherAlerts 提供详情，weather Response 处理选中的数据产品。
- `[MITM]`：正式脚本版只声明 weatherkit.apple.com，客户端用已有证书解密相关 HTTPS 流量。

Storage=Argument 表示模块参数优先，未提供项可从 BoxJs 读取；PersistentStore 只使用持久设置；database 使用作者默认设置。日志默认 WARN，诊断日志不应成为正常数据处理所必需。

## 必须保留的设置含义

1. 天气替换范围与空气指数替换目标不同。天气范围使用地区代码；指数目标使用 HJ6332012、EPA_NowCast、EU.EAQI 等标准名称。
2. 内置算法只决定“怎么算”，不能绕过指数目标决定“哪些原始标准要改”。默认转换中国标准，不等于强制转换全球全部标准。
3. `AirQuality.Current.Index.Replace=[]` 应停用指数替换；补齐污染物也不能使外部来源的指数渗入结果。Apple 本来没有可用指数、且用户允许指数替换时，可用补充数据补出指数。
4. `Comparison.ReplaceWhenCurrentChange=false` 应保留已有 Apple 对比。开启或对比缺失时，沿用用户所选昨日来源；来源与今日显示算法不同时，原版会按该来源的今日和昨日数据进行对比，不能一律禁止查询。
5. 填写另一来源 Token 可能是用于预警或昨日数据，不能据此自动改变当前天气来源。备用查询属于 Fork 扩展，需要单独明确开启，默认关闭。
6. 选择 WeatherKit 或取消数据集，应保留相应 Apple 数据；原生 JSON 读取器所需的格式适配与第三方数据替换分别处理。

指南把 Weather.Replace 描述为正则，当前原版源码实际先转数组再用 includes 匹配。本轮保留现有地区列表匹配，不额外引入新的匹配规则。分钟降水和历史空气接口存在供应商权限限制，插件不提供购买或授权能力；通知仍受系统与天气关注城市设置控制。

## 本轮发现与修正

| Fork 先前偏差 | 本轮修正 |
| --- | --- |
| 非空目标列表加上算法选择，被当成全局强制重算 | 恢复目标标准匹配；所有算法仍可在显式选中的标准上使用 |
| 部分污染物补齐也可能触发目标外指数替换 | 有效 Apple 指数与浓度分别保留；空目标列表明确停用指数替换 |
| 计算算法触发后主动清空已有昨日对比，并只允许同算法历史 | 恢复原版对比开关及独立来源，失败保留安全回退 |
| 仅配置另一来源凭据就允许自动备用查询 | 新的 ProviderFallback.Enabled 默认 false，明确开启且满足原数据不可用等条件后才查询 |

保留已验证的 CO 假标修复、数值与单位校验、未知字段保留、逐产品失败回退、请求合并及有界缓存。原版标尺、天气代码转换、预警合并、分钟降水类和 availability 合并类与上游文件保持同字节。

## 兼容与证据边界

v2 原路径继续保留。iOS 27.3 的 WK3 JSON 协商目前限主天气 App；未知后台、组件和手表客户端保留 Apple 传输。此前天气可显示不代表所有消费者已获得自定义替换，这是一项兼容范围限制，不能作为永久删减原功能来描述。

本轮新增以原版发布默认值为基线的测试，分别检查目标名单、None、部分补齐、昨日对比开关、独立来源和备用查询的明确同意；原有算法测试改为明确选择要转换的标准。自动测试和编译产物检查与真实设备验证分别记录。See [Mac native observations](mac-native-validation.md) for the actual native coverage and remaining limits.
