# WK3 失败回退的临时分配优化

日期：2026-11-16。该后续改动基于 PR #107 的 bc3fc5c，在现有提交后追加，不改变原版名称、版本策略、下载地址、参数或源码署名。

需要适配的 Apple JSON 会在供应商替换前生成有界的安全回退。若供应商全部失败或没有实际变化，原实现还会重复序列化相同正文。现在只记录是否安装了不同的有效产品：全部无变化时等待所有回调后复用已有回退，有变化时保留原编码、验证及超限回退。没有跨请求缓存、合并、重试、额外请求或客户端 API 变化。

## 测量范围

实际压缩 Loon 脚本在 macOS arm64、Node v22.23.5/V8 中回放自写的 273 小时、periodic、未知字段和模拟供应商回调。主测四种场景每版／模式七个独立进程并交替执行，共 112 样本；CPU 另以每版／场景 21 进程、三场景复核，共 126 样本。同场景完整输出 SHA-256 一致、请求和完成各一次，真实网络请求为零。

| 大回应失败样本 | 原版 | 优化 |
| --- | ---: | ---: |
| 回应序列化次数 | 2 | 1 |
| 采样分配 KiB | 3094.0 | 2523.0 |
| CPU 复核中位数 ms | 17.774 | 14.841 |

采样分配减少约 18.5%，CPU 复核中位数减少约 16.5%；等待及完成后保留堆基本不变。成功路径 CPU 复核中位数增加约 2.4%，已兼容失败路径减少约 1.8%，对照四分位区间重叠，不能推断全路径改善。4096 字节间隔采样包含回收对象和框架开销，不等于精确累计分配、Loon/Surge/JSC 原生峰值、常驻内存、设备耗电或 VPN 稳定性测量。

依赖使用本地恢复环境，没有新 npm ci。Terser 实装 5.51.2、锁定 5.49.0，其余核对的 Rollup、schema、util、FlatBuffers 版本一致；同一工具链重建的未修改旧版压缩字节与发布基准一致，隔离了该工具差异。正式 CI 另外使用锁定安装。

## 本 PR 验证

共享 JSON 业务源码的旧、新两版分别与量测基准及候选一致；本 PR 继续按自己的 .loon.bundle.js 文件名重新构建。新增两个回调顺序保护用例覆盖全部失败时等待、适配正文和未知字段保留、旧实体头/bodyBytes 清理与原输入不变。当前独立工作树 432 项测试、实际 Loon 脚本 52 项、表达式/jq 15 项均通过；Fork 的四项改名测试不带入本 PR。

原有来源、13 项设置、12 项默认值、超时边界、预警、AQ、降水、periodic、304/ETag 和失败保留保持。旧轮设备及用户反馈不作为本次内存的重复真机验收；本次未操作客户端或 VPN。

完整 238 个原始样本与所有对照见 [量测 JSON](json-fallback-memory-2026-11-16.json)。复现：`node --expose-gc scripts/measure-json-memory.mjs BASELINE_BUNDLE CANDIDATE_BUNDLE OUTPUT_JSON`，可将候选指向本 PR 的 `dist/response.loon.bundle.js`。

## 后续 Mac Loon 原生观测

同日发布 v3.3.8 后，用户单独更新插件并打开 Apple 天气，取得两次主天气原生脚本完成记录（884 ms、12 ms，异常标记均为 0）及同窗口的原生模型缓存更新。每脚本 startMemory/endMemory 均为空；宿主 RSS 只是未隔离的前后快照，未进行旧／新版原生 A/B，也未确认触发本文供应商全部失败的夹具路径。因此本文 18.5%／16.5% 仍是离线量测，不能当作真机内存／CPU 降幅。完整数据和限制见 [本轮 Mac Loon 记录](mac-loon-v338-2026-11-16.md) 及其 JSON。
